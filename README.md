# exo-skills

Internal skill repository for the Exocortex project.

## Skills

### midjourney-prompt

Compose ready-to-paste Midjourney `/imagine` prompts from natural language descriptions. Describe what you want, get a formatted prompt to drop into Discord.

**Use when:** You need a Midjourney prompt and don't want to fuss with syntax and parameters.

**Location:** `midjourney-prompt/`

### phext

Read, write, and navigate phext documents using shell scripts.

**Use when:** Working with `.phext` files, navigating scroll coordinates, or extracting content from the lattice.

**Location:** `phext/`

### syncthing-ollama

Setup and manage Syncthing for peer-to-peer Ollama model sharing across ranch machines.

**Use when:** Configuring distributed model synchronization, enabling all machines to share a unified model library, or troubleshooting model replication issues across the network.

**Location:** `syncthing-ollama/`
